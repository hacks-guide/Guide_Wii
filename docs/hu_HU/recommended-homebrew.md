# Ajánlott homebrew programok

Ez az oldal bemutat érdekes dolgokat, amit letölthetsz és használhatsz, most, hogy kilockoltad a Wii-od teljes potenciálját.

Ezen az oldalon olvashatsz azokról a programokról, amelyeket az útmutató csapata hasznosnak, érdemesnek vagy simán jónak ítél. Használd ki a Wiid újdonsült erejét! További homebrew található az [Open Shop Channel app könyvtárában](https://oscwii.org/library).

## Eszközök és szórakozás

| Homebrew                                                       | Leírás                                                                                                                                                                                                                                                                                                         |
| -------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [AnyRegion Changer ME](https://oscwii.org/library/app/ARCME)   | Egy eszköz ami segíthet abban, hogy módosítsd a Wii-od régióját. Ez egy sokoldalú régióváltó alkalmazás, de ha rosszul használják, negatív hatása is lehet, így csak akkor használd ezt a programot, ha tudod, hogy mit csinálsz.                                              |
| [CDBackup](https://oscwii.org/library/app/cdbackup)            | Wii Message Board adat mentése, helyreállítása, törlése.                                                                                                                                                                                                                                       |
| [FTPii](https://oscwii.org/library/app/ftpii)                  | Egy FTP szerver a Wii-odhoz, ami lehetővé teszi a fájlok átvitelét a hálózatodon keresztül.                                                                                                                                                                                                    |
| [NetBSD](https://www.netbsd.org/)                              | Egy BSD disztibúció, kifejezetten a karbantartott verzióval a Wii-hoz is.                                                                                                                                                                                                                      |
| [Schism Tracker](https://oscwii.org/library/app/schismtracker) | Szerkesztő és lejátszó tracker zenéhez (IT, XM, S3M, MOD, stb.). Kipróbálni való zenét a [Modarchive](https://modarchive.org/) oldalon találhatsz.                                                                                          |
| [Wii-Linux](https://wii-linux.org/)                            | Egy aktívan karbantartott és frissített Linux disztribúció.                                                                                                                                                                                                                                    |
| [WiiMC-SS](https://oscwii.org/library/app/WiiMC-SS)            | A WiiMC egy módosított és frissített verziója. Egy teljes médiaközponttá képes változtatni a Wiidet, ami képes zenét-, videókat-, DVD-ket és sok mást lejátszani.                                                                                                              |
| [WiiXplorer-SS](https://oscwii.org/library/app/wiixplorer-ss)  | Ez egy Wii-os fájlkezelő, ami lehetővé teszi a fájlok megtekintését és módosítását az SD kártyán, egy USB-eszközön vagy akár a Wii belső memóriájában is. Ez egy erőteljes eszközzé teszi, ami sérülést okozhat a Wii-odban, ha nem megfelelően használod, szóval légy óvatos. |

## Játék portok és mod-ok

| Homebrew                                                                  | Leírás                                                                                                                                                     |
| ------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [ACCF Deluxe](https://aurumsmods.com/accfdeluxe/)                         | Egy Animal Crossing City Folk mod, ami új tartalmaz ad hozzá, valamint néhány változást a játékmenetben.                                   |
| [CavEX](https://oscwii.org/library/app/cavex)                             | A Minecraft Beta 1.7.3 egy implementációja Wii-ra bizonyos korlátozott szolgáltatásokkal.                  |
| [Cave Story](https://oscwii.org/library/app/cavestory)                    | A Cave Story dekomplilás portja (freeware verzió) a Wii-re.                                                             |
| [CTGP-R](https://www.chadsoft.co.uk/)                                     | A Mario Kart Wii egy moddja, ami 200 új pályát ad a játékhoz és számos extra funkciót.                                                     |
| [Mario Kart Retro Rewind](https://rwfc.net/)                              | Egy Mario Kart Wii mod, ami minden retró pályát hozzáad a Super Mario Kart-tól a Mario Kart 7-ig, és még többet.                           |
| [Newer Super Mario Bros. Wii](https://newerteam.com/wii/) | A New Super Mario Bros. Wii modja, ami hozzáad **128** teljesen új pályát a játékhoz.                                      |
| [OpenTTD](https://oscwii.org/library/app/openttd)                         | Az OpenTTD, nyílt forráskódú verziója a Transport Tycoon Deluxe-nak a Wii-ra.                                                              |
| [Project+](https://projectplusgame.com/)                                  | A Super Smash Bros. Brawl egy modja, amely átalakítja a játékot új térképekkel, karakter kiegyensúlyozással és egyebekkel. |
| [Sonic CD](https://oscwii.org/library/app/SonicCDWii)                     | A Sonic CD 2011 dekompiláció portja a Wii-ra.                                                                                              |

## Emulátorok

| Homebrew                                                                                             | Leírás                                                                                                                                                                                                                        |
| ---------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

| [Genesis Plus GX (Genesis/Mega Drive)](https://oscwii.org/library/app/genplus-gx) | Egy Sega SG-1000-, Sega Master System-, Sega Mega Drive-, Sega Game Gear- és Mega CD-emulátor.                                                                                                                |
| [MAME-Wii (Arcade)](https://oscwii.org/library/app/sdlmame-wii)                   | A MAME egy portja, ami egy arcade emulátor ami sok különböző gépet támogat.                                                                                                                                   |
| [mGBA (GB/GBC/GBA)](https://oscwii.org/library/app/mgba)                          | Az mGBA egy portja, egy Game Boy/Game Boy Color/Game Boy Advance emulátor, Wii-ra.                                                                                                                            |
| [Not64 (N64)](https://oscwii.org/library/app/not64)                               | A Mupen64 Nintendo 64 emulátor 0.5-ös verziójának Wiis átültetése.                                                                                                                            |
| [Snex9x RX (SNES)](https://oscwii.org/library/app/Snes9xRX)                       | Az Snes9x GX SNES / Super Famicom-emulátor alapján készült program, ami extra funkciókkal és teljesítményjavításokkal bővíti azt.                                                                             |
| [WiiMednafen (több rendszer)](https://oscwii.org/library/app/wiimednafen)         | A Mednafen, egy több rendszeres emulátora Wii-ra. Ez a verzió több ritkább konzolt is támogat, mint a Neo Geo Pocket, TurboGrafx 16/PC Engine (CD) és a Bandai Wonderswan. |
| [WiiSX (PS1)](https://oscwii.org/library/app/wiiSX)                               | A PCSX-ReARMed, egy Sony PlayStation emulátor, portja Wii-ra.                                                                                                                                                 |
