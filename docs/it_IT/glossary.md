# Glossario

Questo glossario riporta i termini fondamentali utilizzati in questa guida e nell'ambito del modding di Wii, insieme alle relative definizioni. Le sezioni sono ordinate alfabeticamente. Molti termini hanno articoli, wiki o altro, collegati per ulteriori letture.

Il glossario è ancora in **fase di preparazione** è non è completamente finito. Continueremo ad aggiornarlo man mano che il tempo avanza.

| ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| AHBPROT | Acronimo di **A**dvanced **H**ardware **B**us **Prot**ection. È una funzione di sicurezza che disabilita l'accesso diretto a molte delle funzioni dell'hardware di Wii. Un homebrew può impostare un flag che disabilita questa funzione, fornendo così molte delle funzionalità che normalmente sarebbero disponibili solo coi cIOS. |

## K

| Termine    | Definizione                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| KOR        |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| Korean Key | Chiave specifica utilizzata per crittografare i giochi e i software su Wii coreane. È programmata nel SEEPROM. Sulla versione 4.2 o successive del menu, il software di sistema controlla che due condizioni siano vere: o Wii non coreana e senza chiave, o Wii coreana e con chiave. Se nessuna delle condizioni è vera, causa un [Errore 003](bricks#koreankiierror-003-brick). |
