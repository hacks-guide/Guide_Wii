# Glossary

This glossary provides the foundational terms used on this guide and in the Wii modding scene in general, alongside definitions. Sections are sorted alphabetically. Many terms have articles, wiki or otherwise, linked for further reading.

| AHBPROT | Stands for **A**dvanced **H**ardware **B**us **Prot**ection. It is a security feature that disables direct access to many functions of the Nintendo Wii hardware. A flag can be set in homebrew that disables this feature, thus providing many features that would normally only be available with cIOS. |

## K

| Term | Definition |
| ---- | ---------- |
| KOR  | |
| Korean Key | A specific key used to encrypt games and software on Korean Wiis. It is programmed into the Wii's SEEPROM. On Wii's version 4.2 or higher, the Wii system software checks for two conditions to be true - either a non-Korean Wii without the Korean Key, or a Korean Wii with the Korean Key. If neither of these conditions are true, it causes [Error 003](bricks#koreankiierror-003-brick). |
